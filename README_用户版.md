# 模型训练 - 用户版

这个文件夹是便携交付版。日常只需要双击 `模型训练.bat`，不要手动改 `pipeline`、`screener`、`model` 里的文件。

## 每天怎么用

1. 双击 `模型训练.bat`。
2. 点「选择文件夹」，选择今天下载 CSV/XLSX 的文件夹。
3. 在列表里选中今天要导入的文件，可以选任意数量。
4. 点「生成今日筛选 HTML」。
5. 浏览器会打开筛选页，删除不要的卡片。
6. 在筛选页点「保存筛选后HTML」。
7. 如果要看基础数据分析，回到程序点「数据分析」。
8. 如果要丢掉当前模型，让本次数据自己从0训练并预测自己，点右上角「清空模型缓存」后再生成。

## 程序实际做了什么

1. 导入：把你选中的 CSV/XLSX 复制到 `data_store/raw`，多文件会先合并去重。
2. 清洗：根据 `words/banned.txt` 去掉违禁词；默认不排除衣橱收纳类目。
3. 预测：默认先读取昨天模型，对今天商品打分并排序；如果模型缓存已清空，则先用今天数据从0训练，再预测今天。
4. 训练：今天 HTML 生成后，程序会立刻用今天清洗数据增量训练，作为明天模型。
5. 图片：先把未缓存主图全部尝试下载一遍，再只重试失败图片，最多 retry 3 轮；日志会实时显示首轮和 retry 进度。
6. 清理：训练完成后删除训练中间文件（artifacts 等），**保留**主图缓存与向量缓存；模型权重在 `screener/model` 与 `data_store/lgb`。
7. 输出：生成浏览器筛选 HTML，文件名不带“分享”两个字；人工删除不要的卡片后保存。

## 文件夹说明

- `KitchenApp.py`：用户界面入口。
- `模型训练.bat`：双击启动。
- `runtime/`：便携 Python 环境和离线文本模型缓存。
- `screener/model/`：当前模型 bundle，包含权重、特征名、类目映射和元数据。
- `data_store/`：用户数据、图片缓存、输出 HTML、日志和训练闭环数据。
- `data_store/output/`：每天生成的筛选 HTML。
- `data_store/logs/`：运行日志和诊断包。

## 出错时

先点「生成诊断包」，把生成的 zip 发给维护人员。诊断包包含日志、配置、文件清单、输入样本和模型校验结果，不包含完整原始 CSV 和完整模型。

## 注意

- 不要删除 `screener/model/`。
- 不要把旧的 `data_store` 整个覆盖掉；升级程序时保留这个目录。
- 图片下载会先全量尝试，再只重试失败项；少量图片失败时会继续生成结果，并在日志里显示数量。
- 最后交付或发给别人看的重点文件，是 `data_store/output` 里生成的筛选 HTML。
- 「清空模型缓存」不会删除原始 CSV、输出 HTML、日志和离线运行环境；下一次生成会自动从0训练。
